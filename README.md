# CreditSense---Capstone-Project
Demo for the Capstone.

# How to use
1. You need to have Python 3.12
2. Create and activate a venv
3. Install the requirements
4. Initialize the RAG with python -m scripts.initialize_rag --curated-only
5. If its successfull, then you need to put an Anthropic API Key in .env
6. Launch the program with python main.py PATH_OF_THE_PDF_FILE_WITH_THE_STATEMENT
7. Open the dashboard.html file in a browser
